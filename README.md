# 🏡🧸 Wondertown Stories

**Family pretend-play browser world with home, garden, and market scenes, characters, a toy box, story cards, customization, and save/import/export controls.**

🏷️ Maintained in [qamotech/wondertown](https://github.com/qamotech/wondertown) · 🌐 Public repository

## ✨ What is here

- 🏠 Home, garden, and market environments.
- 🧸 Toy-box and character-customization interfaces.
- 📖 Story cards and surprise prompts.
- 💾 Save, export/import, photo, undo/redo, and grown-up settings.

## 🧭 Try the project

Open Wondertown-Stories-Production.html, start playing, choose a scene, add characters or toys, try a story card, and export a saved play session.

## 🚀 Local setup

```sh
git clone https://github.com/qamotech/wondertown.git
cd wondertown
```

Use a current browser. Serve the repository root to preserve relative assets and a stable browser origin:

```sh
python -m http.server 8000
```

Open `http://localhost:8000/Wondertown-Stories-Production.html`. Keep related assets beside the entry file. No npm setup is declared in the inspected repository.

## ⚙️ Configuration & data

This is a pretend-play tool, not a secure multi-user platform. Keep a backup before resets. Browser storage and downloads behave differently across devices.

Keep credentials, private exports, customer records, and personal information out of commits and screenshots. A local browser demo is not evidence of account security, reliable persistence, or connected external services. Preserve exports before changing storage keys or resetting an application.
